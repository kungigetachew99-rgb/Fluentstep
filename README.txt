# FluentStep — English Learning App

## Included features
- Mobile-first dashboard and learning statistics
- Vocabulary add/list/search/delete and spaced revision (1, 3, 7, 14, 30 days)
- Short grammar lessons and multiple-choice exercises
- English text-to-speech and microphone recording/playback
- Daily task checklist and reminder preference
- Weekly activity report
- Local device storage (your data stays in this browser)

## Open on Android
1. Extract this ZIP.
2. Open `index.html` in Chrome or another modern browser.
3. For the best app-like installation, publish the folder to an HTTPS static host, open its URL in Chrome, then use the browser menu → **Add to Home screen** / **Install app**.
4. Microphone recording and notifications may require HTTPS. Browser notification support varies; use your phone's alarm as a reliable backup.

## Important
This first version stores data only in the browser on this device. Clearing browser site data may erase your learning history. Export/cloud sync is not included yet.
